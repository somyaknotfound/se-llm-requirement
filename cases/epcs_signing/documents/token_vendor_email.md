The token model you currently use for VPN access is a one-time-password device
validated to FIPS 140-2 Level 1, so it meets the hard-token criterion for EPCS. The
device is separate from the workstation, which is also required.

Batteries last about five years; we recommend replacing tokens on a five-year cycle.
Lost tokens should be reported to us for deactivation, but deactivating the token on
our side does not revoke the user's signing permission in your application — that has
to be done in the application itself.
