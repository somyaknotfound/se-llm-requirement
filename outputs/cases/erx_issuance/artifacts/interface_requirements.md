# Interface requirements

| Requirement | Statement | Acceptance criteria | Sources |
|---|---|---|---|
| FR-ERX-005 | The system shall integrate interaction and allergy alerts handling into a separate project. | Interaction and allergy alerts handling is integrated into a separate project. | S-PRES-06; S-PRES-09; S-PRES-13 |
| FR-ERX-006 | The system shall receive prescription details including drug name, strength, dose form, quantity, directions for use, and the number of refills authorised when a prescriber requests an e-Rx. | The system receives the required prescription details from the prescriber and verifies that they include the drug name, strength, dose form, quantity, directions for use, and the number of refills authorised to ensure the accuracy of the received prescription details. | S-PHARM-01; S-PHARM-02; S-PHARM-08; S-PHARM-12 |
| NFR-ERX-003 | NFR-ERX-003: The system shall receive e-Rx prescriptions from the hospital EHR network in a format compliant with S-PHARM-14. | The system can receive e-Rx prescriptions from the hospital EHR network in a format compliant with S-PHARM-14. | S-PHARM-04; S-PHARM-10 |
| FR-ERX-009 | The system shall send an electronic CancelRx message to the pharmacy when a cancellation occurs, and the prescriber should be able to see the pharmacy's response. | The system can send an electronic CancelRx message to the pharmacy upon cancellation and display the pharmacy’s response to the prescriber. | S-PHARM-01; S-PHARM-11 |
| NFR-ERX-007 | NFR-ERX-007: The system shall be certified against the ONC criteria for CPOE medications, drug-drug and drug-allergy interaction checks, and electronic prescribing before go-live. | The system is certified against the ONC criteria for CPOE medications, drug-drug and drug-allergy interaction checks, and electronic prescribing. | S-COMP-01; S-COMP-08 |
| FR-ERX-014 | The system shall publish each order as a FHIR R4 MedicationRequest through an adapter, as per S-ARCH-13. | The system must send each prescription order as a FHIR R4 MedicationRequest via the specified adapter, as per S-ARCH-13. | S-ARCH-01; S-ARCH-11; S-ARCH-13 |
| FR-ERX-023 | The system shall transmit electronic prescriptions to community pharmacies through an intermediary. | The system can transmit electronic prescriptions to community pharmacies via the existing e-prescribing intermediary. | DOC-KICKOFF#p2; S-PO-13 |
